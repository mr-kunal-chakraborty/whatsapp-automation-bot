# WhatsApp Automation Bot 🤖

A Node.js based WhatsApp bot built using whatsapp-web.js.

## 🚀 Features
- Auto reply system
- Menu-based interaction
- Query handling system
- "Talk to Human" feature
- Stop command support

## 🛠️ Tech Stack
- Node.js
- whatsapp-web.js

## 📌 How It Works
1. User sends "Hi"
2. Bot shows menu
3. User selects option
4. Bot responds accordingly

## ▶️ Run Locally
npm install
node bot.js
